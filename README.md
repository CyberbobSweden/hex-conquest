# Hex Conquest ⚔

Ett retro pixel-hex erövringsspel, byggt för webbläsare och mobil.
Grunda städer, träna nybyggare och soldater, och erövra dina motståndares kungadömen.

## Spela

👉 **[Spela direkt här](https://cyberbobsweden.github.io/hex-conquest/)** (fungerar när GitHub Pages är aktiverat, se nedan)

## Köra lokalt

Ladda ner `index.html` **och** `music.mp3` (måste ligga i samma mapp) och öppna `index.html` i valfri webbläsare — inget bygge eller npm behövs.

## Publicera med GitHub Pages

1. Gå till repots **Settings → Pages**
2. Under "Build and deployment" väljer du **Source: Deploy from a branch**
3. Välj branch `main` och mapp `/ (root)`
4. Spara — efter ~1 minut är spelet live på `https://cyberbobsweden.github.io/hex-conquest/`
